## 项目简介

DJI 4G Hub 是一款专为 **DJI 第一代 4G 模块（Cellular Dongle）** 开发的 macOS 原生管理工具。

无需修改模块固件，即可在 Mac 上实现：

- 📶 4G / LTE 上网
- 💬 短信收发
- ☎️ 来电监控
- 📱 eSIM 管理
- 🔧 AT 指令调试
- 📊 USB 网络诊断
- 🚀 插入模块自动启动 App（v1.0.1）

所有数据均在本机处理，不上传短信、SIM 卡信息或电话号码。
